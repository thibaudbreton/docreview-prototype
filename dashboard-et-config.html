Compliance
How a Not compliant verdict is handled on this tender.
Gap strategies
What the responsible of a requirement can do about a Not compliant — and what each choice declares to the client. Written for this tender.
The external compliance of a requirement is derived: Compliant when its responsible answers Compliant, otherwise the result of the strategy they pick. A strategy in use can be renamed but not deleted; changing its result recomputes every requirement that uses it, after you confirm.
Capture & segmentation
How the source document is converted, how it is cut into blocks, and how the AI surfaces its uncertainty.
⚠ TE2 — demo only: none of these controls affect how the document is actually segmented or characterised in this build — Allocation's blocks are hand-authored seed data.
Conversion range
Which pages of the source document are captured at all.
Anything outside these pages is not captured, so it produces no requirements at all — this is not a filter on the Allocation table.
Default table conversion format
Whether a table is captured as a picture of itself or as structured data.
Image: faithful to the layout, nothing inside is searchable or extractable. Dataframe: rows and columns become data — which is what lets a table row become a requirement, below.
Default table granularity
How table rows map to requirements on first pass. Only reachable once a table is converted as a dataframe — an image has no rows to map.
Sentences in paragraphs
Whether a paragraph stays one block or is cut into one block per sentence.
Splitting raises the requirement count and can separate a sentence from the one that qualifies it. Kept as the source file has it by default.
Format of equations
Whether an equation is captured as a picture or as a formula.
Document rendering
The core technical trade-off — affects fidelity, overlays and performance on large documents.
Faithful PDF: pixel-perfect to the source, block overlays sit on top. Reconstructed HTML: easier overlays and reflow, approximate fidelity. Decision pending — test on a real tender.
Uncertainty threshold
Below this confidence, a block is flagged "uncertain segmentation" for manual review. Tables are almost always flagged.
80%
⚠ Segmentation confidence is used internally to prioritise; it is not shown as a score.
