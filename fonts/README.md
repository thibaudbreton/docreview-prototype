# Polices de marque

- **Noto Sans** — chargée depuis Google Fonts par chaque écran ; rien à déposer ici.
- **Antarctica** — police de titre de la marque, sous licence, absente des CDN publics. Déposer ici :
  - `Antarctica-Regular.woff2`
  - `Antarctica-Bold.woff2`

Tant que les fichiers manquent, les titres restent en Noto Sans (déclaré en repli) — rien ne casse. Les fichiers ne sont pas versionnés (licence) ; voir `.gitignore`.
